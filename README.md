# Deep Learning Assignments (DL-2026, SIBAU)

Coursework for the Deep Learning course, built with Python, TensorFlow/Keras, pandas and Google Colab.

## Assignment 1: Playing with Text
- **Task 1:** Tweet emotion classification (6 classes) using a dense neural network
- **Task 2:** BBC Sports news classification (5 classes) using a dense neural network

## Assignment 2: Image Classification with CNN
- Scene classification on a subset of the Intel Image dataset (6 classes)
- CNN compared with and without data augmentation and dropout

## Datasets
Datasets are not included in this repo.
- Intel Image Classification: https://www.kaggle.com/datasets/puneet6060/intel-image-classification
- Tweet emotions and BBC Sports: provided through the course LMS

## Running
Open any notebook in Google Colab, mount Google Drive, and update the dataset path to match your Drive.
